# -Cacau-no-Programa-Espacial-
Jogo educacional 2D de química que esta sendo feito na Godot Engine, ambientado no Centro de Lançamento de Alcântara. Cacau, uma menina prestes a ser recrutada como astronauta explora um laboratório em estilo metroidvania, resolvendo puzzles de reações e balanceamento para conquistar os elementos essenciais à vida como conhecemos (CHONPS)
